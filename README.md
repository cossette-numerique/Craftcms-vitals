# Craft Vitals

Module de surveillance des mises à jour pour Craft CMS.

## Installation

1. Clonez ce repository dans le dossier `modules` de votre projet Craft CMS :

2. Entrée la variable VITALS_TOKEN="votre-token-ici" dans le fichier `.env`

Vous pourrez suivre les vitals avec l'url suivante : {URL_DU_PROJET}/vitals/updates?token=votre-token-ici
